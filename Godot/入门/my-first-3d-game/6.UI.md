# UI

为 main 节点创建一个 Control（UI 基类）子节点，命名为 UserInterface，再为其创建一个 Label 子节点命名为 ScoreLabel

UI 的编辑和预览需要在“2D”视图模式才能查看

设置其文本为“Score: 0”作为占位符，设置其 ThemeOverrides-Color-FontColor 为黑色（以便在白色背景展示）

## Theme

Control 节点本身虽然无法渲染出什么东西，但它可以让我们以树状结构组织 UI 元素，让特定一组 UI 元素共享同一个 Theme

选中 UserInterface 节点，为其创建一个新的 Theme（会看到一个 Theme 编辑器）

默认情况下，一个 Theme 仅包含三哥属性：基础缩放、基础字体、基础字体大小

选择项目资源提供的 fonts 目录下那个字体，尺寸选择 22，可以看到 Label 已经用上它了

## mob 击杀时增加分数

```cs
public partial class ScoreLabel : Label
{
    private int _score = 0;

	public void OnMobSquashed()
	{
		_score += 1;
		Text = $"Score: {_score}";
	}
}
```

我们需要 mob 在被击杀后，通知 ScoreLabel 增加分数。但问题是 mob 是动态生成的，我们无法在编辑器中连接信号，这时需要以编程的方式进行连接

在 main.cs 中，使用`+=`进行事件注册（即信号连接），让 mob.Squashed 能引发 UI 的分数增加

```cs
private void OnMobTimerTimeout()
{
    // ...
    // We connect the mob to the score label to update the score upon squashing one.
    mob.Squashed += GetNode<ScoreLabel>("UserInterface/ScoreLabel").OnMobSquashed;
}
```

gd 版本中：使用`.connect()`方法进行连接 

```gd
func _on_mob_timer_timeout():
	#...
    mob.squashed.connect($UserInterface/ScoreLabel._on_mob_squashed.bind())
```

在 Label 的脚本中，执行实际的文本替换逻辑：

```cs
public void OnMobSquashed()
{
    _score += 1;
    Text = $"Score: {_score}";
}
```

问题记录：脚本挂错到了 UserInterface.cs 上，导致未能执行。另外，确保脚本文件名与节点名完全一致。

## 玩家死亡时显示“重试”蒙层

在 UserInterface 下创建一个`ColorRect`子节点，命名为 Retry，Retry 下添加一个 Label 子节点。

在“锚点预设”中，设置 Retry “占满”。发现它并没有占满，这是由于它的锚点是相对于父级 UI 元素（UserInterface）的，所以 UserInterface 也需要设置占满（相对于视口），才能让 Retry 占满屏幕。

为其 Color 属性设置一个带透明度的黑色。

设置 Label 为“正中间”，文本为“Press Enter to retry”

```cs
	private Control _retry;

  	public override void _Ready()
  	{
		// 游戏启动时，初始隐藏 retry 蒙层
		_retry = GetNode<Control>("UserInterface/Retry");
		_retry?.Hide();	
  	}

    private void OnPlayerHit()
	{
		// 显示 retry 蒙层
		_retry?.Show();

		// 停止 mob 生成定时器
		GetNode<Timer>("MobTimer").Stop();
	}

  	public override void _UnhandledInput(InputEvent @event)
	{
		// 如果当前按下了 Enter 键，而且 retry 蒙层可见（当前玩家是“已死亡”状态）
		if(@event.IsActionPressed("retry") && _retry.Visible)
		{
			GetTree().ReloadCurrentScene(); // 重新开始整个 main 场景
		}
	}
```

`_UnhandledInput`会被任意输入触发。

## 音乐（Autoload）

创建新场景 music_player.tscn 根节点为`AudioStreamPlayer`，为其设置音频流（art 目录下的 ogg 文件），勾选 AutoPlay 属性。

在`项目-项目设置-全局-自动加载`中，添加 music_player.tscn。这会让游戏启动时自动加载该场景（开始播放音乐）

游戏开始运行后，scene 树会出现 local 和 remote 两个 tab，切换到 remote 可以查看当前游戏进程的实际节点树。

可以看到，使用 autoload 的情况下，music_player 是与 main 平级的，他们共同属于 root 节点。这避免了 main 节点 reload 时让音乐从头开始。
