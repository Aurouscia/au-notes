# 动画

为 Player 节点创建 AnimationPlayer 子节点，下方会多出一个“动画”tab，打开它。

工具栏中有“autoload”按钮，将其勾选可以让动画自动开始播放。一个“图钉”按钮，勾选可以让本面板在节点取消选中时不消失，仍然展示。一个 range 控件，用于控制时间轴的视觉缩放。

在下拉框处新建名为“float”动画。

选中 Character 节点，打开 Transform，此时每个属性都有“钥匙”按钮，代表“插入关键帧”。

在 0.2s 插入位置 0,0,0 旋转 0,0,0 的关键帧

在 0.5s 插入旋转 8,0,0 的关键帧，在 0.8s 插入位移 0,0.65,0 的关键帧（旋转先于位移）

在 1.2s（末尾）插入 0,0.35,0 和 -9,0,0 

选中关键帧后，拖动曲线可以制造 ease-in 和 ease-out 插值效果

## 节点分层的作用

动画控制的是 Character 而非 Player 本身，因为如果其旋转和位移被动画控制了，就无法再用代码控制移动。所以，用 Player 本身控制角色（全局坐标）移动，Pivot 控制模型朝向，Character 播放动画，互不干扰

## 控制动画速度

用一下代码，使角色在移动时以 4 倍速度播放 float 动画

```cs
    if (direction != Vector3.Zero)
    {
        // ...
        GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 4;
    }
    else
    {
        GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = 1;
    }
```

## 起跳落下arc效果

```cs
    var pivot = GetNode<Node3D>("Pivot");
    pivot.Rotation = new Vector3(Mathf.Pi / 6.0f * Velocity.Y / JumpImpulse, pivot.Rotation.Y, pivot.Rotation.Z);
```

## mob 动画

选中 AnimationPlayer，动画-管理动画，点击 float 右侧的“复制”按钮。

为 mob 添加 AnimationPlayer 节点，动画-管理动画，新建库（名称留空），从剪切板粘贴，确认退出后，勾选自动播放和循环。

让 mob 根据随机出的速度播放动画：

```cs
GetNode<AnimationPlayer>("AnimationPlayer").SpeedScale = randomSpeed / MinSpeed;
```
