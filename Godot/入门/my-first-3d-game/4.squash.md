# 玩家与mob的交互

每个物理物体都有 layer 和 mask 属性。layer 决定它在什么物理层上，mask 决定它能与哪些层的物体发生交互。如果两个物体要互相交互，那么至少有一个的 mask 对应对方的。

合适的 layer 和 mask 设置可以提升性能，避免不必要的计算。

默认情况下，所有物体都是 layer 为 1，mask 为 1 的。

layer 可以起名字，便于标记它的作用，在 项目-项目设置-常规-层名称-3D物理 中，设置层 1、2、3 分别为 player、enemies、world

## 设置 layer 和 mask

选中 Ground，打开 Inspector 的 CollisionObject3D-Collision 菜单。layer 选中 3，取消 1（鼠标 hover 可以看到其名称，右侧的三个点可以展开更直观的选择菜单），mask 完全取消，因为 Ground 不需要监听任何物理事件，只需要防止玩家掉落。

选中 Player，layer 选中 1，mask 选中 2 和 3。

选中 Mob，layer 选中 2，mask 全部取消（这会让 mob 互相穿过）。

mob 不需要 mask world，因为设计上它们只会在 XZ 平面运动，不会下落。

## 跳跃

在 player.cs 中

```cs
[Export]
public int JumpImpulse { get; set; } = 20;

public override void _PhysicsProcess(double delta)
{
    // ...

    if (IsOnFloor() && Input.IsActionJustPressed("jump"))
    {
        _targetVelocity.Y = JumpImpulse;
    }

    // ...
}
```

由于玩家已有“不在地板上就自动下落”逻辑，这里只需赋值“Y方向速度”固定值即可实现“起跳/下落”效果。Input.IsActionJustPressed 适用于空格跳跃这种一次性操作。

## 检测“踩扁”

打开 mob 节点的分组菜单，创建新分组“mob”。mob 节点旁会出现一个方框，这代表它已经至少属于一个组。这可以让玩家判断碰撞是与地面发生的还是与 mob 发生的。

在“跳跃”后添加：

```cs
	// 遍历本帧所有碰撞
	for (int index = 0; index < GetSlideCollisionCount(); index++)
	{
		// 通过索引获取其中一个
		KinematicCollision3D collision = GetSlideCollision(index);

		// 如果碰撞对象是 Mob（C# 里使用模式匹配+类型，而不是分组名）
		if (collision.GetCollider() is Mob mob)
		{
			// 检查碰撞是否是从上方发生的
			if (Vector3.Up.Dot(collision.GetNormal()) > 0.1f)
			{
				// 如果是的，那么踩爆 mob，然后“反弹一下”
				mob.Squash();
				_targetVelocity.Y = BounceImpulse;
				// 避免更多的调用
				break;
			}
		}
	}
```

### GD 版本

```gd
	# 遍历本帧所有碰撞
	for index in range(get_slide_collision_count()):
		# 通过索引获取其中一个
		var collision = get_slide_collision(index)

		# 如果对一个 mob 有多次碰撞，那么第一次之后 mob 就会被删掉，这里检查一下对象是否为 null，以避免后续出现问题
		if collision.get_collider() == null:
			continue

		# 如果碰撞对象在 mob 组中
		if collision.get_collider().is_in_group("mob"):
			var mob = collision.get_collider()
			# 检查是否是从上方碰撞的
			if Vector3.UP.dot(collision.get_normal()) > 0.1:
				mob.squash()
				target_velocity.y = bounce_impulse
				# 阻止多次调用
				break
```

### 解释

`GetSlideCollisionCount`和`GetSlideCollision`都来自 CharacterBody3D，与`MoveAndSlide`有关

后者返回一个`KinematicCollision3D`对象，它持有关于“碰撞是在哪/怎么发生的”的信息。例如，我们使用其`GetCollider`来检查我们是否与 mob 相撞了（通过类型模式匹配或组名）

## 接收“踩扁”

```cs
// Don't forget to rebuild the project so the editor knows about the new signal.

// Emitted when the player jumped on the mob.
[Signal]
public delegate void SquashedEventHandler(); // godot 会自动为 EventHandler 结尾的 Signal 生成事件（编辑器中可以看到）

// 给 player 那边调用的“踩扁”方法
public void Squash()
{
    EmitSignal(SignalName.Squashed);
    QueueFree();
}
```
