# 创建玩家场景

这个小游戏需要创建三个 scene： Player, Mob, HUD

对于较大的项目，最好是把各种 scene 分目录放置，小游戏直接放在项目根目录即可（以 `res://` 标识）

接下来，为玩家单独创建一个 scene，可以让它变得独立于游戏其他部分，易于测试

注意：这里的“场景”是 Godot 术语，指一个可复用的节点树，而不是传统意义上的“场景”

## 根节点

我们需要为玩家选择选择一个根 node 以开始。一般来说，一个场景的根 node 应该体现该对象的本质（它是什么，它应该有什么功能？）此处我们选择 `Area2D`

添加 Area2D node 后，会看到警告：“它没有形状（Shape），所以无法进行碰撞检测”，这可以暂时无视，最好是添加 Sprite 后，再添加匹配视觉效果的 Shape

双击它，重命名为 Player

添加子节点前，选中 Player，在顶部的菜单启用“编组所选节点”，这会导致：任何子节点选中时，也会同时选中父节点，避免相对位置被意外破坏

## 动画节点

选中根节点，使用 command+A 为其创建子节点，搜索 `AnimatedSprite2D`，这个节点可控制玩家的外观和动画

这个节点需要 Sprite Frames，选中它进入 inspector，点击 Sprite Frames 右侧的`<empty>`，下拉框中为它新建 SpriteFrames

点击刚刚新建的 SpriteFrame，可以打开 SpriteFrame 视图

左侧列表是动画列表。点击 default 将其重命名为 walk，然后另外添加一个 up

将 art 目录的四张图片拖动到 walk 和 up 的右侧（该动画的帧）

动画列表顶部的 FPS 可以调整动画播放速度

## 调整尺寸

选中 Player，找到其 inspector 中的 Node2D 下的 Transform 属性，调整 scale 为 0.5 0.5

## 添加碰撞箱

为 Player 节点新增 Collision2D，在 inspector 中为其选择最合适的 capsule 形状，视图中可通过拉动手柄编辑其形状，使其贴合图片素材的轮廓

现在 Area2D 的警告应该会消失，因为它有形状了

## 添加脚本

右键 Player 节点，为其添加脚本

```gd
extends Area2D

@export var speed = 400 # How fast the player will move (pixels/sec).
var screen_size # Size of the game window.
```

```cs
using Godot;

public partial class Player : Area2D
{
    [Export]
    public int Speed { get; set; } = 400; // How fast the player will move (pixels/sec).

    public Vector2 ScreenSize; // Size of the game window.
}
```

使用`@export`或`[Export]`标注一个属性可以在 inspector 中编辑，编辑时会覆盖其默认值（脚本不会被对应地更改）

接下来，应该让 Player 在启动时获取当前视口尺寸

```gd
func _ready():
	screen_size = get_viewport_rect().size
```

```cs
public override void _Ready()
{
    ScreenSize = GetViewportRect().Size;
}
```

## 设置输入

`项目-项目设置-输入映射`内可以添加动作和对应的输入

这里添加四个动作`move_up`、`move_down`、`move_left`、`move_right`，分别添加输入为键盘方向键

然后在脚本中添加：

```gd
func _process(delta):
	var velocity = Vector2.ZERO # The player's movement vector.
	if Input.is_action_pressed("move_right"):
		velocity.x += 1
	if Input.is_action_pressed("move_left"):
		velocity.x -= 1
	if Input.is_action_pressed("move_down"):
		velocity.y += 1
	if Input.is_action_pressed("move_up"):
		velocity.y -= 1

	if velocity.length() > 0:
		velocity = velocity.normalized() * speed
		$AnimatedSprite2D.play()
	else:
		$AnimatedSprite2D.stop()
```

```cs
public override void _Process(double delta)
{
    var velocity = Vector2.Zero; // The player's movement vector.

    if (Input.IsActionPressed("move_right"))
        velocity.X += 1;

    if (Input.IsActionPressed("move_left"))
        velocity.X -= 1;

    if (Input.IsActionPressed("move_down"))
        velocity.Y += 1;

    if (Input.IsActionPressed("move_up"))
        velocity.Y -= 1;

    var animatedSprite2D = GetNode<AnimatedSprite2D>("AnimatedSprite2D");

    if (velocity.Length() > 0)
    {
        velocity = velocity.Normalized() * Speed;
        animatedSprite2D.Play();
    }
    else
        animatedSprite2D.Stop();
}
```

- `velocity.Normalized()` 可以将 `(1, 1)` 变为 `(sqrt(2)/2, sqrt(2)/2)`（长度为1）
- gd 里，可以通过 `$+名称` 获取节点，作用相当于 `get_node()`

## 按需切换动画

- `Animation` 动画可指定当前播放的动画名称（大小写敏感）
- `FlipV`和`FlipH` 可指定垂直和水平翻转

```gd
if velocity.x != 0:
	$AnimatedSprite2D.animation = "walk"
	$AnimatedSprite2D.flip_v = false
	# See the note below about the following boolean assignment.
	$AnimatedSprite2D.flip_h = velocity.x < 0
elif velocity.y != 0:
	$AnimatedSprite2D.animation = "up"
	$AnimatedSprite2D.flip_v = velocity.y > 0
```

```cs
if (velocity.X != 0)
{
    animatedSprite2D.Animation = "walk";
    animatedSprite2D.FlipV = false;
    // See the note below about the following boolean assignment.
    animatedSprite2D.FlipH = velocity.X < 0;
}
else if (velocity.Y != 0)
{
    animatedSprite2D.Animation = "up";
    animatedSprite2D.FlipV = velocity.Y > 0;
}
```

## 碰撞事件处理

由于敌人会是 `RigidBody2D` 类型，所以会触发玩家的 `OnBodyEnter` 事件，需要编写其处理函数：

- 让玩家消失
- 触发自定义的 `Hit` 事件
- 关闭碰撞检测，避免重复触发
- 代码编辑完后，build 并在`信号`面板连接它，让`body_entered`触发处理函数

在碰撞事件处理到一半时不能将其关闭，否则会出问题，所以 SetDeferred 让其延迟执行

```gd
func _on_body_entered(_body):
	hide() # Player disappears after being hit.
	hit.emit()
	# Must be deferred as we can't change physics properties on a physics callback.
	$CollisionShape2D.set_deferred("disabled", true)
```

```cs
// We also specified this function name in PascalCase in the editor's connection window.
private void OnBodyEntered(Node2D body)
{
    Hide(); // Player disappears after being hit.
    EmitSignal(SignalName.Hit);
    // Must be deferred as we can't change physics properties on a physics callback.
    GetNode<CollisionShape2D>("CollisionShape2D").SetDeferred(CollisionShape2D.PropertyName.Disabled, true);
}
```

## 添加重置函数

创建一个函数，用于启动或重置游戏

里面需要设置玩家到指定的起始点，让玩家 Sprite 开始显示，并启动碰撞检测

```gd
func start(pos):
	position = pos
	show()
	$CollisionShape2D.disabled = false
```

```cs
public void Start(Vector2 position)
{
    Position = position;
    Show();
    GetNode<CollisionShape2D>("CollisionShape2D").Disabled = false;
}
```
