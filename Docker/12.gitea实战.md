# gitea

准备好镜像 `gitea/gitea`

## 创建目录

```sh
mkdir -p ~/gitea && cd ~/gitea
```

## 最简单的启动

（SQLite 数据库，无需额外配置）

```sh
docker run -d \
  --name gitea \
  --restart always \
  -p 3000:3000 \
  -p 2222:22 \
  -v $(pwd)/data:/data \
  gitea/gitea:latest
```

## nginx 反向代理到容器

先设置好 dns，然后：

```conf
# Nginx 示例
server {
    server_name git.yourdomain.com;
    
    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

确保上述文件被 nginx include

## ssh 访问

创建密钥对，在用户设置中粘贴公钥

使用`2222`端口（docker run 时映射的）进行操作 git@git.example.com:2222/xxx/xxx
