# 骨架（Armature）

## 分层结构

ROOT
├── Hips
│   ├── Spine
│   │   ├── Chest
│   │   │   ├── Neck
│   │   │   │   └── Head
│   │   │   ├── Shoulder.L → UpperArm.L → LowerArm.L → Hand.L
│   │   │   └── Shoulder.R → UpperArm.R → LowerArm.R → Hand.R
│   └── Leg.L → Knee.L → Foot.L → Toe.L
└── ...（面部骨骼等）

- 骨骼朝向：Y轴指向子骨骼（Blender默认），方便动画师理解旋转方向
- 命名规范：使用 .L / .R 后缀，方便镜像和脚本处理
    - 只建半边，用 Armature → Symmetrize（快捷键 Shift+Ctrl+M）镜像
    - 确保命名带 .L，镜像后自动生成 .R
- Rest Pose：选择T-Pose或A-Pose，不要选复杂姿势作为Rest Pose，否则权重绘制会地狱
- 父子关系操作
    - 先选一个或多个子物体，再选一个父物体，ctrl+P可以建立父子关系
    - Alt+P解除父子关系
    - shift+G可以选择当前物体的父物体，子物体，直接子物体，平级物体
    - 在大纲视图可以选择某个物体及其所有子孙物体
- 父物体变换时，子物体的属性会保持不变
    - 这是因为子物体的属性是相对于父物体的

## 权重绘制

一个顶点可以被多个骨骼影响，但影响总和通常应为1.0（Blender会自动归一化，但手动控制更精确）。

- **权重值：** 0（蓝色）→ 1（红色），建议用 **0, 0.25, 0.5, 0.75, 1** 这几个档位
- **模糊笔刷：** 用于过渡区域（如肩膀、臀部）
- **添加/减去：** 按住 `Ctrl` 切换
- **自动归一化** 开启后，给一个骨骼加权重会自动减少其他骨骼的权重

# 导出

推荐格式：glTF 2.0（.glb / .gltf）

- Godot 4.x 对 glTF 的支持是原生级别的，FBX需要额外导入插件且经常出问题
- glTF 是 Khronos Group 标准，Blender和Godot都是一等公民支持
- 支持 PBR 材质、骨骼、权重、形态键、动画直接导出

```
文件 → 导出 → glTF 2.0 (.glb/.gltf)
├── 格式：glTF Binary (.glb)  # 单文件，推荐
├── 包含：
│   ├── ✓ 选中物体
│   ├── ✓ 动画（如果Blender里有）
│   ├── ✓ 形态键（Shape Keys）
│   ├── ✓ 蒙皮（Skinning）
│   └── ✓ PBR材质（如果需要）
├── 变换：
│   └── +Y Up  # 关键！Godot默认Y-Up，Blender默认Z-Up
├── 数据：
│   ├── ✓ 应用修改器（必须勾选）
│   └── 骨骼：使用Rest Pose作为绑定姿势
└── 动画：
    └── 采样动画（如果导出动画）
```

特别注意：应用所有transform

- 选中骨架，进入 Pose Mode
- Pose → Clear All Transforms（Alt+G, Alt+R, Alt+S）
- 确认模型回到Rest Pose状态
- 再导出

## 能共通的部分

这些是跨引擎通用的，可以放心使用：

### 骨骼层级

- 父子层级关系完全保留
- 命名中的 .L / .R 在Godot中会被识别为镜像对
- Rest Pose 就是Godot中的绑定姿势（Bind Pose）

### 顶点权重

- 每顶点最多4个骨骼影响（这是glTF标准上限，也是GPU骨骼动画的常规限制）
- 如果超过4个，Blender导出时会按权重值自动截取前4个
- 建议：在Blender里就控制每个顶点不超过4个骨骼影响，避免意外截断

### 形态键（Shape Keys）

- glTF 支持导出，Godot 4.x 支持导入
- 在Godot中会成为 Blend Shapes
- 可以在Godot中用 set_blend_shape_value() 控制

### 材质

- glTF 的 PBR 工作流（metallic/roughness）直接对应 Godot 的 StandardMaterial3D
- 纹理会被嵌入 .glb 或作为外部文件引用

## blender独有的部分（避免使用）

| Blender特性                   | 问题                                       | 替代方案                           |
| ----------------------------- | ----------------------------------------- | --------------------------------- |
| **约束（Constraints）**        | 不导出！IK、Spline IK、Damped Track等全部丢失 | 在Godot中用代码或AnimationPlayer实现 |
| **驱动器（Drivers）**          | 不导出！形态键的骨骼驱动失效                    | 在Godot中写脚本控制Blend Shape      |
| **骨骼形状（Bone Shape）**      | 不导出，仅视觉辅助                           | 在Godot中重新做控制器                |
| **自定义骨骼属性**              | 不导出                                      | 在Godot中定义                      |
| **Blender的Action编辑器复杂动画** | 可以导出，但建议简化                        | 在Godot中重新组织动画状态机           |
| **物理模拟（布料、软体）**        | 不导出                                     | 在Godot中使用引擎物理                |
| **粒子系统**                   | 不导出                                     | 在Godot中用GPUParticles3D           |
| **修改器（Modifiers）**        | 必须**应用**后再导出，否则可能出错              | 导出前 Ctrl+A 应用所有修改器          |
| **曲线对象（Curves）**          | 不直接支持骨骼绑定                           | 转换为网格或不用                     |

## 特殊部位最佳实践

### 面部：简化骨骼，保留形态键

- Blender中：
    - 保留基础面部骨骼（下颌、眼球、眼睑等）
    - 形态键做主要表情（微笑、皱眉、眨眼等）
    - **不要**在Blender里给形态键加骨骼驱动器（驱动器不导出）
- Godot中：
    ```csharp
    // 在Godot中控制Blend Shape
    MeshInstance3D mesh;
    // 假设形态键叫 "smile"
    mesh.SetBlendShapeValue("smile", 0.5f);
    ```
    如果需要骨骼控制表情，在Godot中写脚本：
    ```csharp
    // 根据骨骼旋转驱动形态键
    float jawOpen = skeleton.GetBonePoseRotation(jawBoneIdx).X; // 简化示例
    mesh.SetBlendShapeValue("jaw_open", Mathf.Clamp(jawOpen * 10, 0, 1));
    ```

### 尾巴：放弃Spline IK，用链式骨骼

- Blender中：
    - 用 纯FK链式骨骼（Tail01→Tail02→Tail03...）
    - 不要用Spline IK（约束不导出，导出了也没用）
- Godot中实现摆动：
    - 方案A：在Godot中写程序化动画（procedural animation）
    - 方案B：用 SkeletonIK3D 节点（Godot内置的IK）
    - 方案C：写脚本实现延迟跟随（类似Blender的Wiggle Bones）

## 职责分离（什么在blender做，什么在godot做）

- 坐下、挥手、攻击、走路循环：blender内制作关键帧动画，导出到 glTF
- 尾巴摆动、头发飘动：godot控制，程序化/物理
- 表情混合（微笑+惊讶）：blender内制作形态键动画，并导出；godot运行时脚本混合
- 看向目标、头部跟踪：godot代码控制
- IK 解算（脚踩地面、手扶墙）：Godot 的 SkeletonIK3D

- 固定动作（坐下、挥手、走路）→ Blender 做关键帧动画 → glTF 导出 → Godot 播放
- 动态/响应式动作（看目标、尾巴摆动）→ Godot 中代码或 IK 控制
- 两者可以共存：同一个角色可以有导出的动画片段，同时附加脚本控制某些骨骼的实时行为。

### glTF动画导出要点

- 在 Dope Sheet → Action Editor 中创建动画
- 命名规范：Idle, Walk, Attack, Sit 等
- 确保骨骼在 Pose Mode 下制作动画
- 动画基于 Rest Pose 计算，所以 Rest Pose 必须正确

```
glTF 导出：
├── 动画：
│   ├── ✓ 关键帧动画（默认勾选）
│   └── 采样动画：建议勾选
│       （把约束/驱动器烘焙成关键帧，避免丢失）
└── 数据 → 骨骼：
    └── 使用 Rest Pose 作为绑定姿势
```

采样动画（Sampling）：把每帧都烘焙成关键帧，文件会变大，但兼容性最好。如果动画简单，可以不勾选，让 glTF 保留原始关键帧。

```cs
// 在 Godot 中播放动画
AnimationPlayer animPlayer = GetNode<AnimationPlayer>("AnimationPlayer");
animPlayer.Play("Sit");      // 坐下
animPlayer.Play("Wave");     // 挥手
animPlayer.Play("Walk", customBlend: 0.2f); // 带过渡混合
```
