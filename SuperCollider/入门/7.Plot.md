# plot

```scd
{ PinkNoise.ar(0.2) + SinOsc.ar(440, 0, 0.2) + Saw.ar(660, 0.2) }.plot;
```

把 play 的位置替换成 plot，即可可视化声音的波形

plot 的第一参数为“范围”，默认 0.01 秒，也可以手动指定

# scope

把 play 的位置替换成 scope，即可一边播放一边查看实时波形，类似示波器的效果

可以双声道

```scd
{ [SinOsc.ar(440, 0, 0.2), SinOsc.ar(442, 0, 0.2)] }.scope(zoom: 10);
```

## s.scope

服务器也可以输出实时波形，开始播放后，使用 s.scope 显示
