# 关键帧

关键帧用于插值动画，指定物体在某时间的位置和旋转，关键帧之间的部分自动计算得出。

可视化：如果当前活动对象（名称会显示在左上角）处于关键帧状态，则其名称会变为黄色。

## 插值（interpolation）

插值由动画曲线（F-Curves）决定，它可以在曲线编辑器中查看和编辑（右键关键帧，在右侧的面板中选择关键帧的插值模式）。

插值模式是主要设置，有常量、二次、线性、贝塞尔等多种。除了贝塞尔需要额外手动控制，其他的都是自动计算的。贝塞尔的 handle 也有多种类型，有的需要手动控制位置，但其中三种则是自动计算的。

自动插值由侧边栏的“活动函数曲线-控制柄平滑”决定，尽量使用其默认值（持续加速度），因为它会考虑整个曲线，使其更加平滑。

外插值（extrapolation）决定了第一帧之前和最后一帧之后的参数行为。

关键帧类型：可右键设置关键帧类型，用于视觉上标记它们

## 插入关键帧

- 在 3D 视图使用快捷键 `I` 会根据用户设置的“默认关键帧通道”进行关键帧插入
- 当 keying set 被设置时，会覆盖用户设置内的通道
- 鼠标 hover 到属性输入框上 I 也可以插入
- 3D 视图中使用快捷键 `K` 可以展开 keying set 选项，以特定的 keying set 进行关键帧插入
- `Alt+I`/`option+I` 可以移除当前关键帧
- `Shift+Alt+I` 可以清除当前物体所有关键帧（mac上好像没有对应的）

自动插入关键帧（时间轴上方的圆圈，启动后变为红色圆形，代表“录像中”）启用后，拖动标头然后进行 3D 视图内的移动/旋转操作即可生成关键帧。记得关。

## 插帧集（keying set）

keying set 用于以特定方式批量操作关键帧

`shift+K`可以选择当前的活动插帧集（包括内置的和用户自定义的）

鼠标 hover 到特定属性输入框上，右键选择“添加到插帧集”即可将其加入插帧集，或者使用快捷键 `K`
