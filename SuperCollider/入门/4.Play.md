# Play

```scd
{ SinOsc.ar(440, 0, 0.2) }.play;
```

创建一个函数并播放它（不指定服务器，即为默认服务器）

`SinOsc` 是一个类名，全称为 sine wave oscillator（正弦波振荡器，可产生固定频率的正弦波信号）
`.ar` 是它的一个静态方法，作用是实例化 audio rate

SinOsc 是 “unit generator” 的一个例子，简称 UGen，它们是用于生成音频或控制信号的对象。

SC 以采样组（group of samples）——称为 blocks——来计算音频。Audio rate 意味着 UGen 会为 block 中的每个采样计算一个值。有另一个静态方法，称为 kr（control rate）意味着为每个 block 计算一个值，这能节省许多算力，适用于控制其他 UGens，但不适用于控制音频。

SinOsc.ar 的三个参数用于决定产生的实例的参数，它们分别是频率、相位、系数。频率的单位是赫兹（Hz），或每秒周期数（cps）。相位代表它会从什么地方开始周期，对于 SinOsc 来说，相位是弧度制的。系数即为震动的幅度大小。

## 嵌套 UGen

Osc 的参数也可以是 Osc，例如：

```scd
(
{ var ampOsc;
    ampOsc = SinOsc.kr(0.5, 1.5pi, 0.5, 0.5);
    SinOsc.ar(440, 0, ampOsc);
}.play;
)
```
