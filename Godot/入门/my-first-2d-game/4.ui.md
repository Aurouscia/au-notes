# UI

本游戏的 UI 需要：

- 分数，随着 ScoreTimer 的触发而自增
- 信息，例如“游戏结束”和“准备好！”
- 开始按钮

## 场景

先创建一个 scene，根节点选择 CanvasLayer，命名为 HUD

接下来开始创建子节点：

- Label 节点，命名为 ScoreLabel
- Label 节点，命名为 Message
- Button 节点，命名为 StartButton
- Timer 节点，命名为 MessageTimer

在 `ScoreLabel - ThemeOverrides - Fonts` 中，点击“加载”，选择项目目录下的 ttf 文件，设置其 Text 为 “0”

对 Message 和 StartButton 重复上述选择字体操作

选中一个 Control 对象时，可以拖动其四角的 Anchor 

视图右上角会出现新按钮，其中有“Anchor 预设”，点击其项目可以快速设置 Anchor （例如顶部铺满宽度等）

Label 的属性中可以控制文字左右居中（Horizontal Align）

ScoreLabel：

- Text 设为 “0”
- 文字水平和竖直都居中
- Anchor Preset 设为顶部水平居中全幅

Message：

- Text 设为 “Dodge the Creeps!”
- 文字水平和竖直都居中
- Autowrap Mode 设为 Word ，否则文字可能左右超出边界
- Anchor Preset 设为水平居中全幅

StartButton：

- Text 设为 “Start”
- `Control - Layout - Transform` 下，设置 Size X 200， Size Y 100（让文字和边框之间有点空）
- Anchor Preset 底部居中
- `Control - Layout - Transform`, 设置 Position Y 580.

MessageTimer：

- Wait Time 2 
- One Shot "On".

## 脚本

注意：类名、文件名、场景名必须完全对应（class Hud / Hud.cs / hud.tscn）

```gd
extends CanvasLayer

# Notifies `Main` node that the button has been pressed
signal start_game

func show_message(text):
	$Message.text = text
	$Message.show()
	$MessageTimer.start()

func show_game_over():
	show_message("Game Over")
	# Wait until the MessageTimer has counted down.
	await $MessageTimer.timeout

	$Message.text = "Dodge the Creeps!"
	$Message.show()
	# Make a one-shot timer and wait for it to finish.
	await get_tree().create_timer(1.0).timeout
	$StartButton.show()

func update_score(score):
	$ScoreLabel.text = str(score)

func _on_start_button_pressed():
	$StartButton.hide()
	start_game.emit()

func _on_message_timer_timeout():
	$Message.hide()
```

```cs
using Godot;

public partial class Hud : CanvasLayer
{
	[Signal]
	public delegate void StartGameEventHandler();

	public void ShowMessage(string text)
	{
		var message = GetNode<Label>("Message");
		message.Text = text;
		message.Show();

		// MessageTimer 是编辑器中定义的 one shot 2s 定时器，作用是使每个信息显示 2s，这里启动它，2s 后它触发 timeout 信号让信息消失
		GetNode<Timer>("MessageTimer").Start();
	}
	
	async public void ShowGameOver()
	{
		ShowMessage("Game Over");

		var messageTimer = GetNode<Timer>("MessageTimer");
		await ToSignal(messageTimer, Timer.SignalName.Timeout); // 阻塞式等待“信息显示 2s”的时间过去

		var message = GetNode<Label>("Message");
		message.Text = "Dodge the Creeps!"; // 恢复游戏标题
		message.Show(); // 常驻显示（不启动定时器）

		// 创建临时的一次性定时器（结束后会自动释放内存），并阻塞式等待它
		await ToSignal(GetTree().CreateTimer(1.0), SceneTreeTimer.SignalName.Timeout);
		GetNode<Button>("StartButton").Show(); // 1s 后重新显示开始按钮
	}

	public void UpdateScore(int score)
	{
		GetNode<Label>("ScoreLabel").Text = score.ToString();
	}

	// 通过信号编辑器连接，让 StartButton 的按下能触发本函数
	private void OnStartButtonPressed()
	{
		GetNode<Button>("StartButton").Hide();
		EmitSignal(SignalName.StartGame);
	}

	// 通过信号编辑器连接，让 MessageTimer 时间到后触发本函数
	private void OnMessageTimerTimeout()
	{
		GetNode<Label>("Message").Hide();
	}
}
```

## 实例化

把 HUD 节点实例化到 main 场景下，然后：

- 连接 StartGame 信号到 Main 节点的 NewGame 方法
- 移除 Ready 方法内的 NewGame 调用（否则会自动开始）
- 为 NewGame 添加：
    ```gd
    $HUD.update_score(score)
    $HUD.show_message("Get Ready")
    ```
    ```cs
    var hud = GetNode<Hud>("HUD");
    hud.UpdateScore(_score);
    hud.ShowMessage("Get Ready!");
    ```
- 为 GameOver 添加：
    ```gd
    $HUD.show_game_over()
    ```
    ```cs
    GetNode<Hud>("HUD").ShowGameOver();
    ```
- 为 OnScoreTimerTimeout 添加：
    ```gd
    $HUD.update_score(score)
    ```
    ```cs
    GetNode<HUD>("HUD").UpdateScore(_score);
    ```
