# 创建敌人场景

创建新场景，以及以下节点树

- RigidBody2D（命名为 Mob）
    - AnimatedSprite2D
    - CollisionShape2D
    - VisibleOnScreenNotifier2D

选中 Mob，然后点击 Group 按钮，确保不会意外移动其子节点

选中 Mob，在 inspector 内的 RigidBody2D 部分，将其重力设为 0，避免它往下掉

选中 Mob，在 inspector 内的 CollisionObject2D（RigidBody2D 的父类）部分，将其 Mask 取消勾选 1 （让其不扫描碰撞）

选中 AnimationSprite2D，创建并设置其动画，可通过动画面板顶部的播放按钮预览效果

调整 AnimationSprite2D 的 scale 为 0.75 0.75

选中 CollisionShape2D，为其添加形状。如果 capsule 的方向不对，可以设置 transform 内的 rotation 为 90

## 敌人脚本

选中 Mob，右键新建脚本

在 Ready 时，获取动画名称数组，从中随机选择一个动画，开始播放

- gd 中使用 Array 函数转换为数组，并使用 pick_random 随机选中一个
- cs 中得到的直接就是数组，使用 `%` 将随机整数限定在 0~n-1 的范围内
- 注意 play 的调用方式不同

```gd
func _ready():
	var mob_types = Array($AnimatedSprite2D.sprite_frames.get_animation_names())
	$AnimatedSprite2D.animation = mob_types.pick_random()
	$AnimatedSprite2D.play()
```

```cs
public override void _Ready()
{
	var animatedSprite2D = GetNode<AnimatedSprite2D>("AnimatedSprite2D");
	string[] mobTypes = animatedSprite2D.SpriteFrames.GetAnimationNames();
	animatedSprite2D.Play(mobTypes[GD.Randi() % mobTypes.Length]);
}
```

## 让敌人在离开画面时删除自己

QueueFree 即为令本帧结束时“释放”或“删除”当前对象

选中 VisibleOnScreenNotifier2D 节点，设置 exited 信号

```gd
func _on_visible_on_screen_notifier_2d_screen_exited():
	queue_free()
```

```cs
private void OnVisibleOnScreenNotifier2DScreenExited()
{
    QueueFree();
}
```
