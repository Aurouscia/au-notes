# 加载和实例化

1. `var scene = GD.Load(tscn文件路径)`
    - 文件路径为`res://`开头，`.tscn`结尾
    - 返回结果为 PackedScene 类型（没有类型信息）
2. `var node = scene.Instantiate<T>`
    - PackedScene 实例化为对象（节点）
    - `T`必须和 tscn 的脚本类型保持一致
    - 创建的节点不会有效，因为还没有加入节点树
3. `AddChild(node)`
    - 让节点实际开始生效

```gd
var plume_scene = load("res://EnginePlume.tscn")
_plume = plume_scene.instantiate()
add_child(_plume)
```

```cs
PackedScene plumeScene = GD.Load<PackedScene>("res://EnginePlume.tscn");
_plume = plumeScene.Instantiate<EnginePlume>();
AddChild(_plume);
```

# 大型项目最佳实践

使用如下做法，可以消除分散的路径硬编码（改仅需改一处），也不需要写泛型参数

```cs
	/// <summary>
	/// 场景工厂：集中管理 .tscn 的加载与实例化。
	/// </summary>
	public static class SceneFactory
	{
		private static PackedScene _playerScene;
		private static PackedScene _obstacleScene;
		private static PackedScene _enginePlumeScene;

		public static Player CreatePlayer()
		{
			_playerScene ??= GD.Load<PackedScene>("res://player.tscn");
			return _playerScene.Instantiate<Player>();
		}

		public static Obstacle CreateObstacle()
		{
			_obstacleScene ??= GD.Load<PackedScene>("res://Obstacle.tscn");
			return _obstacleScene.Instantiate<Obstacle>();
		}

		public static EnginePlume CreateEnginePlume()
		{
			_enginePlumeScene ??= GD.Load<PackedScene>("res://EnginePlume.tscn");
			return _enginePlumeScene.Instantiate<EnginePlume>();
		}
	}
```
