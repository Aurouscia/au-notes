# 创建项目

首先，创建一个 `Sprite2D` 节点，然后在 FileSystem dock 中找到 icon.svg（godot吉祥物）拖动到节点的 Texture 属性中，让它能显示纹理

提示：直接拖动 icon.svg 到视图中，可以快速创建 `Sprite2D`

# 创建脚本

右键点击 `Sprite2D`，选择 `attach script`，没有脚本时，会自动新建一个

## 新脚本

```gd
extends Sprite2D
```

```cs
using Godot;
using System;

public partial class MySprite2D : Sprite2D
{
}
```

每个 gd 脚本都是一个类，如果要用 cs，则要注意类名必须与文件名匹配

我们的 MySprite2D 必须继承 Sprite2D 类，在 gd 中使用文件顶部的 extends 关键字定义

在编辑器中，属性显示为 `Title Case`（单词首字母大写，空格隔开），而 gd 脚本中对应的变量名命名为 `snake_case`

## 构造函数

```gd
func _init():
	print("Hello, world!")
```

```cs
public MySprite2D()
{
    GD.Print("Hello, world!");
}
```

gd 脚本中，函数用 func 关键字定义，构造函数用 _init 这个保留名称。代码块使用冒号+缩进定义，不要大括号和分号

gd 脚本中，print 是全局函数，而 cs 中需要从 GD 静态类中取用。print 可用于打印调试信息到编辑器中。

## 旋转

```gd
var speed = 400
var angular_speed = PI

func _process(delta):
	rotation += angular_speed * delta
```

```cs
private int _speed = 400;
private float _angularSpeed = Mathf.Pi;

public override void _Process(double delta)
{
    Rotation += _angularSpeed * (float)delta;
}
```

godot 使用特定名称的函数 _process 来作为每帧的钩子。它应该接收一个 double 参数 delta，表示本帧距离上一帧的秒数。

下划线开头的表示保留名称（虽然在 cs 里看起来很奇葩，但还是得这么写）

Rotation 是继承自父类 Sprite2D 的属性，这里修改它即可令 MySprite2D 旋转起来（值的变化=角速度*时间）

## 移动

```gd
var velocity = Vector2.UP.rotated(rotation) * speed

position += velocity * delta
```

```cs
var velocity = Vector2.Up.Rotated(Rotation) * _speed;

Position += velocity * (float)delta;
```

Vector2.UP 表示一个二维向量 (0, -1)，其 rotated 方法可以计算旋转后的向量。

本代码表示“向着 MySprite2D 当前的朝向移动 velocity * delta 的距离”

GD 实现了 Vector2 与 float 的乘法运算符，以及 Vector2 之间的加法运算符，所以上述 cs 中的运算可以实现，但要把 double 转为 float 才能实现

# 完整脚本

```gd
extends Sprite2D

var speed = 400
var angular_speed = PI


func _process(delta):
	rotation += angular_speed * delta

	var velocity = Vector2.UP.rotated(rotation) * speed

	position += velocity * delta
```

```cs
using Godot;
using System;

public partial class MySprite2D : Sprite2D
{
    private int _speed = 400;
    private float _angularSpeed = Mathf.Pi;

    public override void _Process(double delta)
    {
        Rotation += _angularSpeed * (float)delta;
        var velocity = Vector2.Up.Rotated(Rotation) * _speed;

        Position += velocity * (float)delta;
    }
}
```
