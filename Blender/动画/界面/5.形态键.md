# 介绍

形态键（Shape key）是用来对物体进行变形（以产生动画效果）的。用其他术语，形态键也可以叫 morph targets 或 blend shapes。

形态键最常用的地方就是角色面部表情动画，例如表情，口型等。在细化骨骼绑定了的角色时，形态键非常适合有机、软体的部分，因为那些地方需要旋转、缩放之外的更精细的设置。

形态键可以针对有顶点的物体设置，例如网格、曲线、表面和晶格。

# 相对/绝对形态键

Blender 中的形态键（Shape Key）分为**绝对形态键（Absolute Shape Keys）**和**相对形态键（Relative Shape Keys）**两种，它们的核心区别在于**时间/帧的依赖关系**和**插值计算方式**。

## 相对形态键（Relative）—— 最常用

这是 Blender 的**默认模式**，用于面部动画、表情变形、肌肉形变等。

### 工作原理
- 每个形态键都相对于**基准形态（Basis）**进行变形
- 变形量通过**值（Value）**参数控制（范围通常为 0.0 ~ 1.0）
- 多个形态键可以**同时混合叠加**

### 特点
| 特性 | 说明 |
|------|------|
| 基准参考 | 始终以 Basis 为参考 |
| 混合方式 | 多个形态键的值可以叠加混合 |
| 应用场景 | 表情动画、角色变形、 corrective shape keys |
| 驱动方式 | 常用骨骼驱动或手动调节 Value |

### 示例
```
Basis（基础脸） → 微笑键(值=0.5) + 眨眼键(值=1.0) + 挑眉键(值=0.3)
```
最终效果是三个变形同时叠加在 Basis 上。

---

## 绝对形态键（Absolute）—— 序列变形

用于**随时间线性推进**的变形序列，如植物生长、建筑建造、角色从A形态渐变到B形态。

### 工作原理
- 形态键之间是**顺序关系**，每个键代表变形序列中的一个**状态**
- 通过**估算时间（Evaluation Time）**参数控制当前处于哪个状态
- 变形是在**相邻两个形态键之间插值**，而不是都基于 Basis

### 特点
| 特性 | 说明 |
|------|------|
| 基准参考 | 第一个形态键是起点，后续依次排列 |
| 混合方式 | **不能混合**，只在相邻两个键之间插值 |
| 应用场景 | 生长动画、形变序列、时间轴驱动的连续变化 |
| 驱动方式 | 通过 Evaluation Time 逐帧推进 |

### 示例
```
Key 1（种子） → Key 2（发芽） → Key 3（幼苗） → Key 4（成熟植物）
```
设置 Evaluation Time = 2.5 时，会在 Key 2 和 Key 3 之间插值。

---

## 核心对比

| 对比项 | 相对形态键 | 绝对形态键 |
|--------|-----------|-----------|
| **参考基准** | 全部相对于 Basis | 相对于序列中的前一个状态 |
| **混合能力** | ✅ 多个可同时叠加 | ❌ 只能两两之间插值 |
| **控制参数** | 每个键独立的 Value | 全局 Evaluation Time |
| **典型用途** | 面部表情、肌肉变形 | 生长、建造、序列变形 |
| **灵活性** | 高，可任意组合 | 低，线性序列 |
| **默认设置** | ✅ 是 | 否 |

---

## 如何选择？

- **做表情、角色变形** → 用 **相对形态键**
- **做生长、建造、连续形变序列** → 用 **绝对形态键**

在 Blender 中，你可以在形态键面板的下拉菜单中切换模式。切换后，现有的形态键会重新解释其数据，所以通常需要在建模初期就确定使用哪种模式。
