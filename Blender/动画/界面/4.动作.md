# Action（中文译名“动作”）

action 是 blender 对动画数据的容器。例如，当你对某物体的位置进行动画，那个动画是存储在 action 而非物体本身里。接着，那个物体使用 action 动起来（类似于物体使用材质来渲染）所有能动画的物体都是这么动的，它们不存储自己的动画。

action 本身也是数据块，所以可以被跨 blend 文件引用，可以使用该特性来组织管理动画数据。例如，如果正在制作一套通用的动画库（行走、跳跃、idle等）可以把它们各个放在自己的 action 里。

## slot

action 内的动画数据进一步组织为插槽（slots），每个 action 含有一系列 slots，每个 slot 内存储不同的动画数据。一个有动画的数据块实际上会指定一个 action 以及其内部的 slot，这才能决定其由什么动画控制。

`物体属性-动画` 中有 action 选择器以及与其相伴的 slot 选择器。

这种设计允许在一份动画数据中为多个数据块分别提供动画。例如，一个会一边蹦哒一边改变颜色的球体，物体本身和它的材质是两个数据块，slots 允许把物体的动画和材质的动画放在一个 action 内集中组织。或者，如果有三个以不同方式蹦哒的球体，它们的动画也可以放入一个 action 的三个 slot 内。

所以，为了让任何东西动起来，action 内部至少有一个 slot。

注意：slots 不是“for”任何数据块的。两个数据块可以共用一个 action 中的同一 slot，让它们使用一样的动画。slots 只是组织动画数据的方式，并不和场景中的任何东西有本质上的绑定。

## slot 名称和关联类型

action 中的每个 slot 都有一个名称，你可以随便起名字。

除了名字之外，slot 还有一个“关联的数据块类型”（例如材质、对象），这会在首次使用时自动调整。

在`动作编辑器（action editor）`中可以选中特定的 action 进行管理，左侧的列表即为其 slots 列表，每个 slot 右侧的图标都表明了其类型。

如果对对象使用了错误的动画 slot 类型，由于属性名不匹配，什么都不会发生。

## F-Curves

F-Curves 是 blender 中动画的最基本单位，也是 action 所包含的主要数据。每个 F-Curve 包含关键帧，定义某属性（例如物体的 x 坐标）应该怎么随着时间变化。

Blender 的动画编辑器，例如动画摄影表、曲线编辑器等，左侧都有一个通道列表，展示所有有动画的属性。对于 action，这些通道每个对应一个 F-Curve。

通道也可以分组，例如，默认情况下 Blender 会给一根骨头的通道分一个组。其他一些冷门功能可能用到通道组，不过都是方便起见。

## Working with actions

当你给一个物体（或其他数据块）加动画时，Blender 会尝试自动找到合适的 action，如果找不到，就会创建一个 action。在 action 赋值后，它也会创建并赋值一个 slot 给数据块。

Blender 用启发（heuristics）来找一个合适的 action，基于“关系紧密的（close related）数据块的动画应该放一个 action 里”这种思想。例如，一个物体和它的数据被认为是关系紧密的，例如：如果一个摄像机已经被设置动画了，然后你再给它的焦距 K 帧（焦距在相机数据里，不在相机对象上）如果对象上有 action，那数据会复用同一个。反过来，先 K 帧焦距，再 K 帧物体，也会复用同一个 action。

其他“close related”的例子包括材质和它的节点树、世界和它的节点树、网格和它们的形态键数据。

注意：这种“close related”有一个例外，那就是数据块有多于一个用户时。例如，一个网格数据被多个网格物体使用，那么“关系”会被忽略，网格数据和其用户会分别得到 action（以避免意料之外的“改一个，改所有”出现）

### 手动赋值 action 和 slots

除了知道 blender 会自动为数据块选择 action 和 slot 外，你还可以手动指定。这可以用来为数据块指定已有的动画（通过选择 action+slot），也可以用来指定数据块的新关键帧会去哪个 action，如果仅指定 action，不指定 slot，新的关键帧会创建新 slot。

对于每个数据块，属性编辑器里会有一个“动画”面板，那里有 action 和 slot 选择器（成套出现），你可以用它们选择 action 和 slot。另外，对于活动物体，动画编辑器的顶部栏也可以进行同样的调整。

你不一定会在下拉框看到所有的 slots，因为这里只会显示类型匹配的。

当你选择一个 action 用来 animate 一个数据块，为了方便起见，blender 会试图选择最合适的 slot（基于类型和名称），如果未找到，它会保持空白，在这种情况下（以及自动选择选错了的情况下）你可以手动更改选择。

### 为多个数据块更换 action

当编辑一个“控制多个数据块动画”的 action 时，你可能要更换 action 为另一个。如果要对所有使用该 action 的数据块同时做本操作（所以所有动画都被一起更换），为了实现这个效果，有以下两个选择。

- 替换动作（动作编辑器中可以找到该按钮）：会为所有使用该 action 的物体替换 action（NLA 片段和约束会排除）
- 重映射用户（右键 outliner（暂未找到是什么东西））：会为 action 的所有用户切换 action（包括 NLA 片段和约束）
