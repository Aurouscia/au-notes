# 骨架（Armature）

`Shift+C`将游标设回世界原点

创建一个骨架，其有以下特点：

- 有原点、位置、旋转和缩放
- 有数据块，可以在编辑模式编辑
- 可以被连接到其他场景，这意味着同一骨架的数据可以跨多个对象复用
- 在对象模式进行的所有动画设置都只作用于整个对象，而不是其内部的骨骼（需要使用姿态模式做这个）

由于骨架设计上就是用来摆姿势的（不论是静态还是动画用途）它们有一个特定的状态，被称为“静置位置”（rest position），这就是骨架的默认形状，其所有骨头的默认位置/旋转/缩放。

在编辑模式，看到的总是其 rest position，而在其他模式（物体模式/姿态模式）看到的是当前的姿势（除非在骨架面板中选择 rest position）

## 骨头（Bone）

骨头是骨架的基本单元，可以分为以下两类：

- 变形骨头（Deforming Bones）：Deform 属性为 true 的骨头。用于把网格中的顶点拉着和它一起走
- 控制骨头（Control Bones）：Deform 属性为 false 的骨头。用于控制其他骨头的行为，例如 IK

骨头的默认显示结构：

轴较粗的那一侧称为 Head 或 Root，另一侧称为 Tail 或 Tip

可在骨架-视图显示中控制显示的内容，如果勾选“轴向”就能看到，每个骨骼的轴向都是自己的局部 Y 轴，法向平面是 XZ 轴，骨骼如果要“扭转”则肯定是沿自己的 Y 轴转动。
