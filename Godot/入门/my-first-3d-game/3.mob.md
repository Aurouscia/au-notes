# 创建 MOB

和 Player 的操作一样，新建场景，创建 CharacterBody3D 根节点命名为 Mob，Node3D 子节点命名为 Pivot，再把 mob.glb 拖拽到 Pivot 上，给 Mob 创建 CollisionShape3D 子节点，选择 BoxShape，调整碰撞箱到合适的大小。

## 离开屏幕时自动销毁

如果 Mob 无限创建会把游戏卡爆，所以需要在离开可视范围时销毁。

如果需要大量创建和销毁某种对象，可考虑 Pooling（池化）。池化仅在 C# 需要，GDScript不需要（没有GC这回事）

为 Mob 节点添加 VisibleOnScreenNotifier3D 子节点，它会在 Mob 离开可视范围时发出信号。它也会在视图中显示为一个长方体，调整其尺寸使其完全包裹模型，避免模型“在视野中突然消失”。

## 脚本

在 Initialize 中：

- 接收 startPosition 和 playerPosition
- 将玩家位置投影到与出生点同一高度，避免玩家跳跃时 mob 抬头
- 使用 LookAtFromPosition 设置自身的位置和朝向的方向（注意第三参数不是旋转轴）
- 使用 GD.RandRange 随机速度标量，用`标量*Vector3.Forward`创建速度向量
- 使用 `Rotated() + Rotation.Y + Up 轴`，将其 Velocity 属性（指的是全局的）旋转到其自己的“前方”
- 随机一个`-Pi/4 ~ Pi/4`的角度偏移（绕 Up 轴）

在 _PhysicsProcess 中 MoveAndSlide

从 VisibleOnScreenNotifier3D 连接信号到 Mob 节点，调用一个 QueueFree，使其在离开屏幕后自行销毁

## 生成

### 生成准备工作

先调整分辨率：项目-项目设置-显示-窗口 720*540

在主场景根节点创建 Node3D 子节点，命名为 Cylinders，为其创建一个 MeshInstance3D，选择圆柱体 Mesh

看着相机预览视图，将其沿着平面向左上角移动，直到刚好移出镜头范围

Command+D 复制一份，向下移动到左下角，然后shift 同时选中它们俩，向右移动到镜头外

现在场景中有四个圆柱体。点击 Mesh 打开其菜单（由于 Mesh 共享，编辑这里应该会同时编辑四个对象），打开 Material，编辑其 Albedo（漫反射）颜色为橙色，以便在白色的地面上看清

在根节点创建 Path3D 节点命名为 SpawnPath，调整视图为顶视图，选中视图顶部的“新节点”工具，分别点击四个圆柱体的位置，最后闭合曲线

Path3D 下创建 PathFollow3D 子节点命名为 SpawnLocation

### 生成脚本逻辑

为 Main 节点附加脚本，添加 Export 属性 PackedScene MobScene，在编辑器中为其选中 mob.tscn

为 Main 节点添加 Timer 子节点，命名为 MobTimer，勾选 AutoStart，时间调整为 0.5s，连接信号到 Main，使用以下代码处理 Timout 事件

```cs
using Godot;
using System;

public partial class Main : Node
{
	[Export]
	public PackedScene MobScene { get;set; }

	public void OnMobTimerTimeout()
	{
		// 实例化 mob 对象
		var mob = MobScene.Instantiate<Mob>();

		// 获取 SpawnLocation 和 Player 对象（注意如果有多层，要使用斜杠分隔）
		var spwanLocation = GetNode<PathFollow3D>("SpawnPath/SpawnLocation");
		var player = GetNode<Player>("Player");

		// 随机一个 0～1 的浮点数，用于设置 Path 上的“比例”
		spwanLocation.ProgressRatio = GD.Randf();

		// 以当前玩家的位置和 SpawnLocation 初始化 mob
		mob.Initialize(spwanLocation.Position, player.Position);
		
		// 将 mob 添加到根节点下
		AddChild(mob);
	}
}
```
