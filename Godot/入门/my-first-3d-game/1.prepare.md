# 创建主场景

创建根节点类型为 Node 的场景，根节点命名为 Main，场景保存为 main.tscn

## 创建地面

为了避免玩家掉下去，需要创建一个地面。地面、墙这种静态碰撞物体可以使用`StaticBody3D`节点（无法被外力移动的 3D 物理物体）。它需要`CollisionShape3D`作为子节点，来控制碰撞箱形状。

为 Main 节点添加 StaticBody3D 节点，重命名为 Ground ，并为其添加 CollisionShape3D 子节点和 MeshInstance3D 子节点。

- 为 CollisionShape3D 子节点创建形状，使用 BoxShape，设置长宽高为 60 60 2
- 为 MeshInstance3D 子节点创建 Mesh，使用 BoxMesh，设置同样的长宽高

将 Ground 整体向下移动 1 单位，使得其上表面 Y 坐标为 0，可以使用以下方法打开吸附：

- 启用视图顶部的磁铁图标
- 拖拽时按住 command/ctrl 键

左下角应该会实时显示移动了多少。最终，Ground 的 transform.position.y 应该变成 -1

## 添加灯光

为 Main 节点创建`DirectionalLight3D`子节点，上移，旋转，使其能照亮地面。把它的“阴影”属性打开（默认没有阴影）
