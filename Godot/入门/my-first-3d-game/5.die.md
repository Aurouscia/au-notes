# 玩家die

为 Player 节点添加子 Area3D 子节点，命名为 MobDetector，其下再创建子节点 CollisionShape3D，选择 cylinder 形状。

把 cylinder 改成饼子形状，向上移动一些。这样，玩家只会在地面时被怪撞死，在空中时不会。

将 MobDetector 的 Monitorable 属性取消勾选（不被其他物体检测到），Monitoring 属性保持勾选（检测其他物体），layer 全部取消（不属于任何层），mask 勾选 2（只检测与 mob 的碰撞）

将其 OnBodyEntered 信号连接到 Player 节点（脚本所在），在 Player 节点添加：

```cs
	[Signal]
	public delegate void HitEventHandler();

	private void Die()
	{
		EmitSignal(SignalName.Hit);
		QueueFree();
	}

	private void OnMobDetectorBodyEntered(Node3D body)
	{
		Die();
	}
```

在 main.tscn 中（注意不是 player.tscn 中）找到 player 节点，将其 Hit 事件连接到 Main 节点（脚本所在），然后添加如下代码，使 mob 停止生成（mob 生成依赖于玩家的位置，如果玩家消失后依然尝试生成，会引发异常）

```cs
	private void OnPlayerHit()
	{
		GetNode<Timer>("MobTimer").Stop();
	}
```
