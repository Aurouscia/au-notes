# signal

signal 是 Godot 中对于观察者模式（Observer Pattern）的实现

这允许一个物体在某种情况下影响另一个物体，而无需直接引用他，有助于降低代码耦合度，让代码更灵活

举例：角色的血量实时反映到血条上，这个可以通过信号来实现

## 实操例子

- 新建一个节点，节点类型选择器中搜索 Button
- 选中 Button 后，右侧 dock 的位置切换 tab 到“信号”
- 双击 pressed，打开“信号连接”面板
- 会自动创建目标方法名（默认名称为`_on_node名_事件名`，例如`_on_button_pressed`）
    - GDScript 可以自动生成该方法到 script 中
    - C# 需要手动添加同名方法（最好是用 PascalCase）
- 添加完后，信号面板中的事件下会会显示他连接到的方法：`../Sprite2D :: OnButtonPressed`
- 开始运行场景点击按钮会执行方法

如果要用按钮切换某个元素是否调用 Process 方法：

可以使用`set_process()`函数和`is_processing()`函数

```gd
func _on_button_pressed():
	set_process(not is_processing())
```

```cs
private void OnButtonPressed()
{
    SetProcess(!IsProcessing());
}
```

## 自动化链接

连接可以由代码来进行，而不是在编辑器中硬设定

- `_ready()`钩子函数在对象初始化之后被调用
- `get_node()`方法可以获取指定名称的**子节点**

```gd
func _ready():
	var timer = get_node("Timer")
    timer.timeout.connect(_on_timer_timeout) # 使用 connect 进行信号连接（事件注册）

func _on_timer_timeout():
	visible = not visible
```

```cs
public override void _Ready()
{
    var timer = GetNode<Timer>("Timer");
    timer.Timeout += OnTimerTimeout; // 注册事件：在 timer.Timeout 发生时，调用本对象的 OnTimerTimeout
}

private void OnTimerTimeout()
{
    Visible = !Visible;
}
```

## 自定义信号

- 在 gd 中，使用 signal 关键字来定义信号
- 在 cs 中，使用 `[Signal] public delegate` 来定义信号

自定义的信号会出现在编辑器的“信号”dock中，可和内置信号一样连接/监听

由于信号表示“刚刚发生的事件”，所以名称应该使用过去时

```gd
extends Node2D

signal health_depleted

var health = 10
```

```cs
using Godot;

public partial class MyNode2D : Node2D
{
    [Signal]
    public delegate void HealthDepletedEventHandler();

    private int _health = 10;
}
```

## 触发自定义信号

GDScript 与 C# 的触发方式不同：

- gd 中，使用 signal 下的 `emit()` 方法
- cs 中，使用父类提供的 `EmitSignal()` ，必须传入 signal 名称

```gd
func take_damage(amount):
	health -= amount
	if health <= 0:
		health_depleted.emit()
```

```cs
public void TakeDamage(int amount)
{
    _health -= amount;

    if (_health <= 0)
    {
        EmitSignal(SignalName.HealthDepleted);
    }
}
```

## 带有参数的信号

使用括号定义信号的参数

```gd
extends Node2D

signal health_changed(old_value, new_value)

var health = 10
```

```cs
using Godot;

public partial class MyNode : Node
{
    [Signal]
    public delegate void HealthChangedEventHandler(int oldValue, int newValue);

    private int _health = 10;
}
```

## 触发信号时带参数

```gd
func take_damage(amount):
	var old_health = health
	health -= amount
	health_changed.emit(old_health, health)
```

```cs
public void TakeDamage(int amount)
{
    int oldHealth = _health;
    _health -= amount;
    EmitSignal(SignalName.HealthChanged, oldHealth, _health);
}
```
