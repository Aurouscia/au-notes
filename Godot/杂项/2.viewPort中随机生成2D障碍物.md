# 随机生成

以下做法未考虑互相重叠的检测，需要进一步优化

```cs
	Vector2 viewportSize = GetViewportRect().Size;
	for (int i = 0; i < 5; i++)
	{
		Obstacle obstacle = SceneFactory.CreateObstacle();
		obstacle.Position = new Vector2(
			(float)GD.RandRange(0, viewportSize.X),
			(float)GD.RandRange(0, viewportSize.Y)
		);
		AddChild(obstacle);
	}
```

# 障碍物

当前物体是一个 `public partial class Obstacle : RigidBody2D`

- 使用几个 Vector2 创建物体形状，形状即为 `Vector2[]`
- `Polygon2D`需要形状，为其赋值形状和颜色后，可以提供视觉效果
- `CollisionPolygon2D`也需要形状，为其赋值形状后，可以提供物理碰撞效果

```cs
	float size = 50.0f;
	Vector2[] square = new Vector2[]
	{
		new Vector2(-size / 2, -size / 2),
		new Vector2(size / 2, -size / 2),
		new Vector2(size / 2, size / 2),
		new Vector2(-size / 2, size / 2)
	};

	// 正方形视觉效果
	Polygon2D visual = new Polygon2D();
	visual.Polygon = square;
	visual.Color = new Color(0.8f, 0.2f, 0.2f);
	AddChild(visual);

	// 与视觉效果形状一致的碰撞箱
	CollisionPolygon2D collision = new CollisionPolygon2D();
	collision.Polygon = square;
	AddChild(collision);

	// 不受重力影响
	GravityScale = 0;
```
