# 内存

free -h 查看可用内存

## 设置虚拟内存（swap）

### 1. 创建 1GB 的 swap 文件（根据你的磁盘空间调整，建议 1-2GB）

`sudo fallocate -l 1G /swapfile`

如果上面报错（比如提示 fallocate 不支持），改用这个：

`sudo dd if=/dev/zero of=/swapfile bs=1M count=1024`

### 2. 设置权限（必须 600，否则 swapon 会警告/拒绝）

`sudo chmod 600 /swapfile`

### 3. 格式化为 swap

`sudo mkswap /swapfile`

### 4. 立即启用

`sudo swapon /swapfile`

### 5. 验证

`free -h`，`swapon --show`

### 6. 开机自启动

`echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab`

## 调整虚拟内存大小

1. 关闭一些服务，使空闲内存大于 swap 占用
2. `sudo swapoff /swapfile`
3. `sudo rm /swapfile`
4. 按上述步骤重新创建
5. 无需更改 /etc/fstab ，因为 /swapfile 这个路径没变
6. 重启那些服务

# 硬盘

- `du -sh ./*` 查看当前目录下各项的大小
- `df -h` 查看所有挂载和可用大小

## journal 过大

`journalctl --vacuum-size=500M`：会立即删除归档的旧日志

## rsyslog（message）过大

修改配置文件 `/etc/rsyslog.conf`

```
*.info;mail.none;authpriv.none;cron.none /var/log/messages
（大约配置文件的54行，修改为：）
*.none /var/log/messages（什么都不记）
```

重启生效：`systemctl restart rsyslog`
