# watch

docker-compose up --watch

作用：把源代码目录的改动自动同步进容器内（需要容器内置热更新机制，才能实际发挥作用）

## 与直接 bind mount 对比

|                | bind mount  | `compose watch`       |
| -------------- | ------------------ | --------------------- |
| **原理**         | 运行时直接挂载宿主目录        | 监听文件事件，主动同步进容器        |
| **文件系统一致性**    | 强一致（同一 inode）      | 最终一致（有微小延迟）           |
| **IDE/编辑器兼容性** | 完美，文件变更立即可见        | 依赖 watch 机制，偶尔漏事件     |
| **跨环境**        | 需要本地 Docker，远程开发麻烦 | 支持远程上下文、云端开发          |
| **选择性同步**      | 难，mount 整个目录       | 容易，可配置 path/ignore    |
| **性能（大量小文件）**  | 可能受宿主机 FS 影响       | 更可控，可忽略 node\_modules |
| **构建缓存**       | dev 层不 COPY，缓存干净   | 与构建缓存无关               |
