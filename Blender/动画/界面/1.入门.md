# 入门

## 两类常用动画

- 直接控制物体/骨骼的位移和旋转
- 形态键

上述二者都可以导出 glTF 作为游戏资产，驱动器不行

## 属性的颜色

blender 中，默认情况下属性输入框是灰色的（类似位置和旋转的地方）

- 黄色：该属性在当前时刻为关键帧（改起来要注意）
- 绿色：该属性在其他帧为关键帧，此值是被插值出来的（随便改无所谓）
- 橙色：该属性被原本被关键帧控制，但现在受到了手动修改（时间轴拖走值就消失了，除非插入/更新关键帧才能保存）
- 紫色：被驱动器控制

属性右侧的菱形标记可以插入/移除该属性的关键帧，插入的快捷键是 I (Insert)

## 主要面板

- 时间线
- Dope Sheet 动画摄影表，可同时管理多个物体的关键帧
- Graph Editor 曲线编辑器，可编辑动画曲线
- NLA Editor 非线性动画，可管理多层的复杂动画
- Drivers Editor 驱动器，可通过属性+表达式实现过程化动画
- Movie Clip Editor
- Video Sequence Editor

## 时间轴操作

时间轴是跨多个页面统一的，它们对时间轴的定位/播放操作都是一样的

- 滚轮缩放
- Alt + 滚轮（mac 上是 option + 滚轮）左右移动标头
- 左键拖动顶部区域移动标头
- shift + 右键拖动任意区域移动标头
- 鼠标拖动时按住 ctrl 键启用吸附（会吸附到关键帧或其他特殊帧）
- shift + 方向键可直接跳到开头/结尾

顶部的磁铁标记可进行更细致的吸附设置

更多时间轴操作和播放见 https://docs.blender.org/manual/en/latest/animation/animation_editors.html
