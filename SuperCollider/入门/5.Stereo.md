# Stereo

SC 中，使用中括号 `[]` 来构造数组

数组可以使用 `.at(x)` 或 `[x]` 来访问元素

数组可以用于表示多声道，例如：

```scd
{ [SinOsc.ar(440, 0, 0.2), SinOsc.ar(500, 0, 0.2)] }.play;
```

可在左耳播放 440 赫兹，右耳播放 500 赫兹

## 多通道展开

由于上述两个 SinOsc 的相位和系数相同，所以可以写为以下格式：

```scd
{ SinOsc.ar([440, 442], 0, 0.2) }.play;
```

这称为 multichannel expansion，如果为 UGen 的参数输入数组，它会成为多个 UGen，参数分别对应数组元素

## choose 例子

```scd
(
{ var freq;
    freq = [[660, 880], [440, 660], 1320, 880].choose;
    SinOsc.ar(freq, 0, 0.2);
}.play;
)
```

choose 可在数组中随机选择一个项

上述例子中，可能播放两边频率不同的效果，也可能两边一样频率

## Pan2

Pan2 也是一个 UGen，用于分配两个通道：

```scd
{ Pan2.ar(PinkNoise.ar(0.2), SinOsc.kr(0.5)) }.play;
```

上述例子可以以 0.5 秒为周期，在“左耳大右耳小”和“左耳小右耳大”之间切换 PinkNoise 声音

Pan2 的第二参数即为通道分配比例，合法值在 -1 到 1 之间
