# 执行文档内代码

使用软件内置的文档查看器时，点击选中代码行（或者选区选中），然后 Shift+Enter 即可执行

注意，每个语句都必须分号结尾

注意，不要把文档改坏了

# postln

打印某对象到控制台，但它不是全局函数，而是任何对象都有的方法，例如：

`"Hello World!".postln`

将会打印 “Hello World!” 字符串。

但控制台会显示两次，这是由于 SC 总会显示最后一个表达式的值，第一次是显式要求的，第二次是表达式的值。

如果有两个 postln 语句，则只有第二个会出现表达式值（仅最后一个）

# 括号

小括号代表一片需要作为整体执行的代码，作为区分，没有小括号的代码每行较为独立

# post window（输出）

cmd+shift+P 清空输出
cmd+\ 置于顶部

# 架构

SuperCollider 分为三个部分：

- IDE
- sclang 语言（客户端）
- 实际计算和合成逻辑（服务端）

它们通过 UDP 或 TCP 通信（但一般在一个设备上）

# 新建源码文件

cmd+N，保存为 `.scd` 文件

像在文档中那样 shift+enter 执行选中代码
