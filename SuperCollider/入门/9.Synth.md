# SynthDef

SC 服务端接收的是字节码，服务端不识别函数或 OOP

SinOsc.ar 等函数实际上是包装器，它们隐式创建了 SynthDef，服务端使用 SynthDef 创建了 synth，synth 才是实际发出声音的东西

SynthDef 和 synth(s) 是类似 class 和 instance 的关系，模板和模板创建的对象

## 创建

```scd
//first the Function
{ SinOsc.ar(440, 0, 0.2) }.play;
​
// now here's an equivalent SynthDef
SynthDef.new("tutorial-SinOsc", { |out| Out.ar(out, SinOsc.ar(440, 0, 0.2)) }).play;
```

SynthDef.new 接收一些参数，第一个是名称（字符串），第二个是函数，又称为“UGen Graph Function”，因为它告诉服务器怎么连接它的多个 UGen

注意：在函数括号内，`|out|` 定义了一个“SynthDef 控制输入”，它接下来被用作 Out.ar 的第一个参数

为每个 SynthDef 创建一个 out 控制是好习惯

## 与函数调用的区别

上述第二例子中的 UGen Graph 函数与第一例子中的很类似，但有一个关键区别：它外面套了一层名为“Out”的 UGen。Out 向服务器的总线写出一个 ar 或 kr 信号，用于播放声音

Out 接收两个参数，第一个参数是总线的索引数字（从 0 开始，一般来说是左侧声道）第二个参数是 UGen 或 UGen 数组，如果你提供一个数组（即多通道输出），那么第一通道将会被播放到指定的总线 index，第二通道将被播放到 index+1，以此类推

这是一个立体声的例子，用于进一步解释：

```scd
(
SynthDef.new("tutorial-SinOsc-stereo", { |out|
    var outArray;
    outArray = [SinOsc.ar(440, 0, 0.2), SinOsc.ar(442, 0, 0.2)];
    Out.ar(out, outArray)
}).play;
)
```

440Hz 的 SinOsc 会被播放到第一个输出总线（即左声道），442Hz 的 SinOsc 会被播放到第二个输出总线（右声道）。默认情况下，out 认为总线 0 是第一个，所以这俩会分别播放到总线 0 和 1

函数 play 和 SynthDef play 都返回 Synth 对象，它代表了服务器上的一个 synth，如果你把它存储到一个变量里，那么就能控制它的行为。例如`free`方法就会造成服务器上的 synth 停止播放，且释放内存，这比`cmd+.`灵活，因为后者会释放所有的 synth

```scd
x = { SinOsc.ar(660, 0, 0.2) }.play;
y = SynthDef.new("tutorial-SinOsc", { |out| Out.ar(out, SinOsc.ar(440, 0, 0.2)) }).play;
x.free;    // free just x
y.free;    // free just y
```

### 创建与播放分离

有时会希望发送字节码到服务器，但不立即创建 synth（不播放）这种时候，可以使用 add 方法：

```scd
// execute first, by itself
SynthDef.new("tutorial-PinkNoise", { |out| Out.ar(out, PinkNoise.ar(0.3)) }).add;
​
// then:
x = Synth.new("tutorial-PinkNoise");
y = Synth.new("tutorial-PinkNoise");
x.free; y.free;
```

这比重复调用 PinkNoise 函数要更高效，因为省去了重复编译和发送的时间

### 固定随机值

```scd
// first with a Function. Note the random frequency each time 'play' is called.
f = { SinOsc.ar(440 + 200.rand, 0, 0.2) };
x = f.play;
y = f.play;
z = f.play;
x.free; y.free; z.free;
​
// Now with a SynthDef. No randomness!
SynthDef("tutorial-NoRand", { |out| Out.ar(out, SinOsc.ar(440 + 200.rand, 0, 0.2)) }).add;
x = Synth("tutorial-NoRand");
y = Synth("tutorial-NoRand");
z = Synth("tutorial-NoRand");
x.free; y.free; z.free;
```

第一个例子中，每次`f.play`都会 evaluate 一遍`200.rand`，生成一个新的随机数

但在第二个例子中，由于函数的参数会被立即 evaluate，`200.rand`会在`SynthDef(...).add`时就变为确定值，后续实例化 synth 时不会再有随机性

## 可选参数

```scd
(
SynthDef("tutorial-args", { arg freq = 440, out = 0;
    Out.ar(out, SinOsc.ar(freq, 0, 0.2));
}).add;
)
x = Synth("tutorial-args");                // no args, so default values
y = Synth("tutorial-args", ["freq", 660]);        // change freq
z = Synth("tutorial-args", ["freq", 880, "out", 1]);    // change freq and output channel
x.free; y.free; z.free;
```

上述例子中，arg 关键字定义了 freq 和 out 两个参数

实例化 synth 时， UGen 的 graph function 的参数可以选择不传入或传入

传入时使用数组，键和值分别作为数组元素传入（pairs of arg names and values）

## 已创建后，动态改变参数

```scd
s.boot;
(
SynthDef.new("tutorial-args", { arg freq = 440, out = 0;
    Out.ar(out, SinOsc.ar(freq, 0, 0.2));
}).add;
)
s.scope; // scope so you can see the effect
x = Synth.new("tutorial-args");
x.set("freq", 660);
x.set("freq", 880, "out", 1);
x.free;
```

用 set 传入 pairs of arg names and values，使其具有新行为

## 字符串和 Symbol 的区别

- 字符串：双引号，例如 "abc"
- Symbol：单引号或反斜杠开头，例如 'abc' 或 \\abc

区别：同样值的 Symbol 会确保是相同的，而字符串无法确定

作为与服务器交互的参数或名称时，它们可以互换，仅在“通用代码”中需要注意这点
