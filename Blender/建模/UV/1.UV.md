# UV

仅在模型完成后展 UV，如果后期模型还有较大调整，那 UV 基本上算是白展的

# 缝合边

要进行 UV 展开，首先在顶部切换到 UV Editing 视图，使用推荐的布局（左侧是 UV 视图，右侧是 3D 视图）

在编辑模式下，选中一些边，右键菜单内可将其标记为缝合边。

一般情况下，选中一些面，右键 UV-展开 会将其 UV 展开，但对于闭合的曲面效果不怎么好，如果能知道“哪些边可以断开”，UV 展开会变得更容易（可以直接全选+展开），效果更好。

简单的工作流：

1. 标记缝合边
2. 全选+展开
3. 检查大致效果是否合适，如果不合适，则返回第 1 步
4. 如果合适，则对 UV 进行手动微调（确保这是最后一步，否则白干）

如果想在 3D 视图检查缝合边是否形成了闭合的多边形，可以使用 L（选择相连）工具，它会自动止于缝合边边缘（在“上个操作”菜单中，可以选择 L 工具的划界方式）

## 最佳实践

| 部位     | 推荐接缝位置          | 原因             |
| ------ | --------------- | -------------- |
| **头部** | 后脑勺中线、耳后        | 面部是视觉焦点，接缝必须隐藏 |
| **躯干** | 腋下、侧腰、脊柱（背部）    | 正面（胸腹）保持完整     |
| **手臂** | 手臂内侧（二头肌/三头肌之间） | 外侧是常见视角        |
| **腿部** | 大腿内侧、小腿后侧       | 正面和侧面保持干净      |
| **手部** | 指缝、手腕内侧         | 手背通常更重要        |
| **脚部** | 脚底、脚踝内侧         | 脚背和侧面可见        |

核心原则：接缝要放在自然褶皱处、不易看到的背面、硬边过渡处。把接缝想象成裁缝的裁剪线——它们必须存在，但应该藏在看不见的地方。

不合适的缝合边（例如直接把人切成前后两半）会导致 UV 扭曲倾斜，这是不同的圆柱体（躯干和腿）强行一体展开的结果

可以用缝合边分割重要/不重要的区域，例如沿着发际线切开前脸和头顶（因为头顶会被头发遮住，所以不需要前脸那样精细的贴图，它们不应该在一个岛上）

## 实时查看效果

打开一个图像编辑器界面，创建一个图像，选择生成类型里的“UV 栅格图”

在模型的材质的漫反射（或类似的需要纹理的地方）选择图像纹理，图像下拉框选中刚刚新建的这个图像

视图里选择材质预览模式，即可看到 UV 展开是否有意外的扭曲倾斜

# 不同展开算法

如果 Unwrap 展开整个人物效果不好，尝试对不同部位使用不同展开方式：

- 面部：Sphere Projection（球面投影）
- 四肢/躯干：Cylinder Projection（圆柱投影）
- 耳朵/复杂结构：Project from View（视角投影）
- 整体微调：Unwrap（基于缝合边的展开）

注意：“xx投影”的展开不会参考缝合边，而是基于当前 3D 视图的视角，如果视角是歪的，那就展开得很奇怪

# 修改器

## 细分

如果模型有细分修改器，UV 依然能正常工作，如果有问题可以调整细分修改器的高级设置中，关于 UV 平滑的设置

## 镜像

如果模型有镜像修改器，且暂不想应用，可以考虑：

- 复制一份模型
- 应用其镜像修改器
- 对其进行 UV 展开
- 为原模型添加“数据传递”修改器，源选择新模型
    - 注意“物体变换”（全局坐标系）必须取消勾选，否则二者无法对应地传递数据
    - 勾选 UV

这样可以使用一个形状一样但应用了镜像修改器的模型，基于两者接近的面，为其提供 UV 数据

# 钉固

确定了某个 UV 岛已满意后，可以 L 全选它，使用“钉固”将其固定。这可以保护已完成的工作，后续再次展开该物体，这片 UV 不会受到影响

在 UV 视图的点模式下，钉固的点会显示为红色

# 横平竖直

如果希望 UV 中的边横平竖直：

先编辑该岛上的一个矩形，以下方式二选一：

- 选中顶点，直接用鼠标调整
- 选中边，右键“自动对齐”或“水平/垂直对齐”，这可以让一条边的两个点 U 或 V 坐标一致

然后，选中该矩形，再 L 选中整个岛，在 3D 视图中选择“沿活动四边面展开”即可获得指定方向的“横平竖直”的 UV 岛

最好是不要斜着，以免后续操作产生锯齿状的边缘

# 重复利用贴图

如果模型和贴图都是左右对称的，可以考虑沿着对称轴切开，然后让两半的 UV 共享半边的贴图区域，这样可以节省图片面积

# 多通道

一个模型可以有多个 UV 通道，可以有不同的展开方式（重叠/不重叠）用于不同的用途
