# 自动移除旧 mob

如果结束一局游戏，立即开始下一局，那么上一局的 mob 还残留着

打开 mob.tscn，切换到 “Groups” 面板，点击加号，创建新分组，名为 mobs

接下来，所有 mob 实例都属于 mobs 分组

## 调用

在 NewGame 中：

```gd
get_tree().call_group("mobs", "queue_free")
```

```cs
GetTree().CallGroup("mobs", Node.MethodName.QueueFree);
```

这会让所有位于 mobs 组中的对象删除自己

# 背景

可以添加一个 ColorRect 或 TextureRect 节点

- 让它是 Main 的第一个子节点（这样才会在最下方）
- 选择 Layout - Full Rect
- 选择颜色

# 音乐

art 目录里有一个背景音乐和一个死亡音效

- 创建两个 AudioStreamPlayer 到 main 场景的子级中，分别命名为 Music 和 DeathSound
- stream 处选择对应的 ogg 文件 
- 对于需要循环播放的音乐：
    - Loop 属性位于 stream 资源中，而不是 Player 本身
    - 先点击“Make Unique”（唯一化）让这个资源不要共享
    - 点击切换 Loop 为 true

## 脚本内播放

```gd
# 结束时
$Music.stop()
$DeathSound.play()

# 开始时
$Music.play()
```

```cs
// 结束时
GetNode<AudioStreamPlayer>("Music").Stop();
GetNode<AudioStreamPlayer>("DeathSound").Play();

// 开始时
GetNode<AudioStreamPlayer>("Music").Play();
```

# 快捷键

- 在 项目设置-输入映射 添加新动作 `start_game`，绑定按钮 Enter 键
- 在 StartButton 的 Inspector 中打开“Shortcut”
- 新建 Shortcut
- 为其 InputEvents 添加一个新元素，选择 InputEventAction
- 给 InputEventAction 的 action 选择 `start_game`
- 现在，点击 Enter 键相当于按了 StartButton
