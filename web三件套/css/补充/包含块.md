# 包含块（Containing Block）

```css
.file-item:hover {
    transform: translateY(-2px);
}
```

只要祖先元素有 transform / perspective / filter，它都会成为内部 position: fixed 元素的包含块。于是 Prompt 的 position: fixed 不再相对于视口，而是相对于被 transform 过的 .file-item，自然就被框在 file-preview 内部了。

修复：在 components/common/Prompt.vue 里用 Vue 的 `<Teleport to="body">` 把 Prompt 的 DOM 直接挂到 `<body>` 下：

```vue
<Teleport to="body">
    <div class="prompt fixFill">...</div>
</Teleport>
```

这样无论调用方嵌套在什么 transform 元素里，Prompt 的包含块始终是视口，会显示在屏幕正中间。
