# 函数

使用大括号`{}`框起来的代码是一个函数，函数可以赋值给标识符，例如：

`f = { "Function evaluated".postln };`

运行这行之后，就可以使用 f 来代指那个函数

## 调用函数

使用 `.value` 来调用（evaluate）函数，获得其值

不同逻辑的函数都可以响应 .value，实现不同效果，这是 OOP 中“多态”（polymorphism）的体现

## 定义和传入参数

参数在函数的开头使用 arg 语句定义，调用时使用 value 后的小括号传入

```scd
(
f = { arg a, b;
    a - b
};
f.value(5, 3);
)
```

- f.value(10, 2);         // regular style
- f.value(b: 2, a: 10);   // keyword style

注意：sclang 没有运算符优先级，固定从左到右算，哪怕是先加后乘（除非使用括号指定优先级）

## 另一种定义参数的语法

使用两个竖杠包围参数列表

```scd
f = { arg a, b;
    a + b
};
g = { |a, b|
    a + b
};
```

## 定义变量

var 变量只能定义在紧跟 arg 的下一行，且仅在函数内有效

```scd
(
f = { arg a, b;
    var firstResult, finalResult;
    firstResult = a + b;
    finalResult = firstResult * 2;
    finalResult
};
f.value(2, 3);    // this will return (2 + 3) * 2 = 10
)
```

如果 var 定义在小括号（代码块内）则仅在那个小括号内有效

## f 怎么能直接赋值？

小写字母 a-z 是预定义的变量，可以直接赋值（例如 s 代表服务器）
