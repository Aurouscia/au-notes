# 屏幕坐标系

Godot 中的 2D 坐标轴，x 正方向向右，y 正方向向下

## 构造

例子：构造一个距离左侧 400，距离顶部 300 的向量，并把 node 设置到它的位置

```gd
$Node2D.position = Vector2(400, 300)
```

```cs
var node2D = GetNode<Node2D>("Node2D");
node2D.Position = new Vector2(400, 300);
```

## 成员访问

```gd
b.x = 3
b.y = 1
```

```cs
b.X = 3;
b.Y = 1;
```

## 运算

gd 和 cs 都支持以下运算：

- 向量与向量相加减
    - 为了找到点 A 指向点 B 的向量，使用 B - A
    - A.direction_to(P)
    - A.DirectionTo(P);
- 向量与标量相乘除
    - 单位时间移动量：normalized 方向 * 速度标量
- 向量的 normalization（长度设为 1）
    - a = a.normalized()
    - a = a.Normalized();
- 法向量
    - 与一个平面垂直，指示其“朝向”的向量叫法向量
- 点乘
    - `A·B = |A| * |B| * cos(theta)`（垂直时为0，平行时为值之积或其相反数）
    - `A·B = Ax * Bx + Ay * By`
    - A 点乘 B 与 B 点乘 A 相等
    - var c = a.dot(b)
    - var c = a.Dot(b);
    - 如果某角色的向量与“它指向敌人的向量”之点积 > 0，说明敌人在他的 180 度视线范围内
        - var AP = A.DirectionTo(P); if (AP.Dot(fA) > 0) GD.Print("A sees P!");
- 叉乘
    - 结果是与两个向量都垂直的第三个向量
    - 拿出右手，弯曲四指，让“弯曲方向”贴合“A旋转到B”的旋转方向，竖起大拇指的方向就是 A 叉乘 B
    - A 叉乘 B 与 B 叉乘 A 是相反数
    - a.cross(b)
    - a.Cross(b);


### 法向量的示例

```gd
var collision: KinematicCollision2D = move_and_collide(velocity * delta)
if collision:
	var reflect = collision.get_remainder().bounce(collision.get_normal())
	velocity = velocity.bounce(collision.get_normal())
	move_and_collide(reflect)
```

```cs
// 尝试移动并检测碰撞，返回碰撞信息（若无碰撞则返回 null）
KinematicCollision2D collision = MoveAndCollide(_velocity * (float)delta);

// 如果发生了碰撞
if (collision != null)
{
    // 计算剩余未完成的位移在碰撞法线方向上的反射向量
    // GetRemainder() 返回本次未完成的位移，Bounce() 将其沿碰撞法线反射
    Vector2 reflect = collision.GetRemainder().Bounce(collision.GetNormal());
    
    // 将速度向量沿碰撞法线反射，实现反弹效果
    _velocity = _velocity.Bounce(collision.GetNormal());
    
    // 用反射后的剩余位移继续移动，处理滑墙/多次碰撞等情况
    MoveAndCollide(reflect);
}
```

### 叉乘的示例

```gd
func get_triangle_normal(a, b, c):
	# Find the surface normal given 3 vertices.
	var side1 = b - a
	var side2 = c - a
	var normal = side1.cross(side2)
	return normal
```

```cs
Vector3 GetTriangleNormal(Vector3 a, Vector3 b, Vector3 c)
{
    // Find the surface normal given 3 vertices.
    var side1 = b - a;
    var side2 = c - a;
    var normal = side1.Cross(side2);
    return normal;
}
```
