# 平面

法向量（normal）是与特定直线(2D) 或 平面(3D)垂直的单位向量

法向量用来指示平面的哪边是“正面”

特定直线/平面法向量指向的那半边空间称为 positive half-space，另外半边称为 negative half-space

## 到平面的距离

对于一个**过原点的**平面，其法向量点乘某点的位置，即该点到平面的距离。

可通过以下几点理解：
- 如果这个点在平面上，那么它的位置向量肯定和平面法向量垂直，距离为0
- 如果这个点在始于(0, 0)的法向量的末端，点积（距离）为 1
- 如果这个点在平行于平面的位置移动，点积（距离）不会变化

```cs
var distance = normal.Dot(point);
```

## 平面的定义

平面不一定经过原点，所以平面需要一个向量（法向量 N）和一个标量（到原点的距离 D）来定义

以下计算可以得到平面上的一个点（离原点最近的那个）：

```cs
var pointInPlane = N * D;
```

以下计算可以得到任意点 `point` 到平面的距离（可理解为其到“过原点”版本的平面的距离，减去 D）

```cs
var distance = N.Dot(point) - D;
```

Godot 提供了内置方法用来计算这个：

```cs
var distance = plane.DistanceTo(point);
```

其中，plane 为 Plane 类型，Plane 类型的常见构造函数：

- `Plane(normal: Vector3)`
- `Plane(normal: Vector3, d: float)`
- `Plane(normal: Vector3, point: Vector3)`

平面上的两个点可以确定两个方向相反的平面（二维坐标内的平面），通过以下方式获得其法向量

```cs
// Calculate vector from `a` to `b`.
var dvec = pointA.DirectionTo(pointB);
// Rotate 90 degrees.
var normal = new Vector2(dvec.Y, -dvec.X);
// Alternatively (depending the desired side of the normal):
// var normal = new Vector2(-dvec.Y, dvec.X);
```

如果要构造位置一样，朝向相反的平面，将 N 和 D 都取反即可

如果要以一个法向量和一个点来构造平面，则：

```cs
var N = normal;
var D = normal.Dot(point); // 根据点乘的定义（cos）易得，这个点积就是 D
```

## 平面的作用

对于一个凸多边形，计算一个点到它所有平面的距离，如果任意一个距离为正，则说明点在外部，否则在内部

对于两个凸多边形，计算它们是否重叠，需要检查多边形 A 的所有点是否在 B 内，以及多边形 B 的所有点是否在 A 内

这个过程称为 Separating Axis Theorem (SAT)

在三维的情况下，这可能不管用，因为两个凸多面体的边垂直着交叉时，上述方法无法检测到重合。解决方法：添加一个检测，将靠近的两条边的叉积方向作为新的平面来检测
