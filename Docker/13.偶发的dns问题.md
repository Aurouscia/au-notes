使用 compose 时，应尽量将数据库容器分配静态 IP，以避免偶发的 dns 问题

例如：

```yaml
services:
  db:
    networks:
      internal:
        # 固定 IP：选高位地址避开 host-local 从低地址开始的动态分配，冲突时 compose 会报错
        ipv4_address: 10.89.1.240
  api:
    depends_on: [db]
    # 写死 db 的 hosts 记录，绕过 dnsmasq 偶发超时导致的 getaddrinfo ENOTFOUND db
    extra_hosts:
      - "db:10.89.1.240"
```
