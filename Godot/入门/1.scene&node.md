# node

node 定义游戏元素的一个基本行为，例如一个物体可能有碰撞箱node，声音源node等。

所有 node 都有以下特点：
- 一个名字
- 可编辑的属性
- 每一帧可接收到对特定函数的调用（钩子）
- 可以用新的属性和函数扩展
- 可以添加到其他 node 下作为子级

正是因为 node 的组合，它们才能形成行为复杂的游戏元素

# scene

scene 定义一个游戏元素，例如一个场景、一个人物或一把武器

当你把 node 组织为单根树状结构时，称为“构造了一个 scene”

一旦保存，这个新 scene 就可以当作新的 node 类型使用（添加到其他 node 下作为子级），在这种情况下，它的树状结构是隐藏起来的，只能看见它本身这个 node

Godot 要求一个主场景（Main Scene）用来启动游戏，其他的随意

Godot 编辑器本质上是一个 scene 编辑器

## 创建 scene

编辑器左侧有一个 scene 面板（Dock）如果当前没有 scene，在那里可以新建指定类型的 scene

当一个 scene 被选中，inspector 面板（Dock）会展示该 scene 的各项属性

使用 Save Scene As 功能时，你只能把它保存到 res:// 目录下（代表项目的资源目录）

## scene 的实例化

当一个 scene 被保存，它可以作为一个蓝图创建任意数量的对象（就像类和对象的关系）这个过程叫实例化（instancing）

编辑器中，选中一个 node，然后点击 dock 顶部的铁链按钮，选择一个 scene 来创建实例到 node 的子级（官方教程中，这个过程是在场景中添加具有物理效果的球体）

修改一个 scene 的属性（默认属性）会导致它所有的实例的属性（如果未指定）一起被修改，但如果实例已经有自己的值，将不会受到影响。如果实例拥有自己的值，其输入框旁边会有一个“还原”按钮，点击它可以还原默认值。

## 最佳实践

官方建议在 Godot 里摒弃“architectural code patterns”，例如 MVC 等，而是把精力集中在“设计 scene 树本身”上，这是更自然的思考方式
