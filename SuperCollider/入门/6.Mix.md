# Mix

UGen 可以使用加号加在一起

```scd
{ PinkNoise.ar(0.2) + SinOsc.ar(440, 0, 0.2) + Saw.ar(660, 0.2) }.play;
```

Saw 指的是锯齿波（比正弦波难听一些）

这种操作也可以使用另一种写法

```scd
// 单通道
{ Mix.new([SinOsc.ar(440, 0, 0.2), Saw.ar(660, 0.2)]).postln }.play;
​
// 双通道
(
{
    var a, b;
    a = [SinOsc.ar(440, 0, 0.2), Saw.ar(662, 0.2)];
    b = [SinOsc.ar(442, 0, 0.2), Saw.ar(660, 0.2)];
    Mix([a, b]).postln;
}.play;
)
```

在例子一中，我们获得了一个 BinaryOpUGen 对象（在这里指的是两个 UGen 加在一起），在例子二中，我们获得了由两个 BinaryOpUGen 组成的数组
⧉
注意：在例子一中使用了`Mix.new(...)`，而在例子二中我们使用了`Mix(...)`，后一个是前一个的缩写。`new()`是最常见的实例化方法，在某些情况下可能有多种，例如 UGen 的`ar()`和`kr()`方法。Mix 只是一个“方便类”，不会真的创建 Mix 对象，而是返回它的加法结果（BinaryOpUGen 或 BinaryOpUGen 数组）

## Mix.fill

```scd
(
    var n = 8;
    { Mix.fill(n, { SinOsc.ar(500 + 500.0.rand, 0, 1 / n) }) }.play;
)
```

Mix.fill 的第一参数是“次数”，该方法的功能为“重复第二参数 n 次并将结果相加”

上述例子展示了”随机 8 个 500-1000Hz 的 SinOsc，并相加“，注意 mul 使用了 1/n，这样它们最大值也只会是 ±1，不会被截断

Mix.fill 会给函数传入 index 参数，有需要的话可以读取

```scd
(
    var n = 8;
    {
        Mix.fill(n, { arg index;
            var freq;
            index.postln;
            freq = 440 + index;
            freq.postln;
            SinOsc.ar(freq , 0, 1 / n)
        })
    }.play;
)
```
